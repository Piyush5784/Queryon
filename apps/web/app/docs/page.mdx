# Documentation

Queryon is a desktop database client for Postgres, MySQL, SQL Server, ClickHouse, DuckDB, and a
dozen more engines. Start with installation.

## Install Queryon

[View install instructions →](/docs/install) for Windows, macOS, and Linux.

## Supported engines

PostgreSQL, Neon, CockroachDB, GreengageDB, MySQL, MariaDB, TiDB, SQLite, SQL Server, StarRocks,
ClickHouse, and DuckDB.

Every engine gets its own real driver — not a generic SQL layer papering over the differences —
so schema editing, data types, and constraint behavior match what that engine actually supports.
